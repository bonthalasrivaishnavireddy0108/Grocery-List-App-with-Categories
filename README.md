#  Grocery List App with Categories

A Java Swing desktop application that helps users manage grocery items by category, search and filter items, calculate the total grocery cost, and save data using file handling.

## Project Overview

The **Grocery List App with Categories** is a Java micro project developed to make grocery shopping more organized and convenient. It provides a graphical user interface where users can add grocery items, organize them into categories, view their list, and calculate the estimated shopping cost.

##  Features

- **Category-Based Management:** Organize groceries into categories.
- **Add Grocery Items:** Enter item details through a graphical interface.
- **Delete Items:** Remove selected grocery records.
- **Search Items:** Find items by name.
- **Category Filter:** Display items belonging to a selected category.
- **Total Price Calculator:** Calculate the estimated cost of all grocery items.
- **File Handling:** Save grocery records locally and load them when the application starts.
- **Java Swing GUI:** Use a desktop interface to interact with the application.

##  How to Run the Project

### Prerequisites

- Java Development Kit (JDK) installed.
- Command Prompt or a Java IDE.

### Steps

1. Download or clone this repository.
2. Open Command Prompt in the folder containing the Java source files.
3. Compile the Java files:

```bash
javac Main.java GroceryItem.java GroceryGUI.java
```

4. Run the application:

```bash
java Main
```

5. Use the graphical interface to manage your grocery list.

##  Data Storage

The application uses a local text file named `groceries.txt` to store grocery records. Saved records can be loaded when the application starts again.
